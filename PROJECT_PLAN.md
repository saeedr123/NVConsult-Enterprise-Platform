# NVConsult Enterprise Platform

## Sprint 1 — Theme Foundation
- Build a custom WordPress theme structure with header, footer, front-page template, and stylesheet.
- Enqueue theme assets and support basic WordPress features.
- Provide editable homepage content via a shared settings option.

## Sprint 2 — Homepage
- Create a frozen homepage layout that preserves the overall structure and visual hierarchy.
- Render hero, services, about, and CTA sections from editable settings.
- Add a lightweight CRM plugin for lead management.

## Architecture
- Theme: wp-content/themes/nvconsult-theme
- Core plugin: wp-content/plugins/nvconsult-core
- CRM plugin: wp-content/plugins/nvconsult-crm

## Notes
- Follow WordPress Coding Standards and PSR-12 style where practical.
- Keep content editable through plugin settings and theme templates.
